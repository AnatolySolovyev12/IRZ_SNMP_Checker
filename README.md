IRZ_SNMP_Checker

What can:

1) Gets a list of hosts from .txt for further work with them via UDP/SNMP.
2) Gets all OIDs and their marks from .txt for further access to hosts.
3) Performs sequential collection of information from hosts via UDP/SNMP with output to the console.
4) Generates a list of hosts who do not have IMSI/Operator/IP on both SIM slots.
5) Sends an informational message with lists of problem hosts in MAX to the target recipient.

Что умеет:

1) Получает список хостов из .txt для дальнейшей работы с ними через UDP/SNMP.
2) Получает все OID и их метки из .txt для дальнейшего доступа к хостам.
3) Выполняет последовательный сбор информации от хостов через UDP/SNMP с выводом на консоль.
4) Формирует список хостов, не имеющих IMSI/Operator/IP в обоих слотах SIM.
5) Отправляет целевому получателю информационное сообщение со списками проблемных хостов в MAX.
